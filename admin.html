← กลับหน้าเว็บผู้ใช้

🖼️ รายการกรอบภาพทั้งหมด

ยังไม่มีกรอบภาพ กดปุ่ม "+ เพิ่มกรอบใหม่" เพื่อเริ่มต้น

✏️ กำหนดรายละเอียดกรอบภาพ

🎯 Frame Editor — กำหนดพื้นที่ใส่ภาพ (Photo Area)

ลากกล่องสีแดงเพื่อย้ายตำแหน่ง / ลากจุดมุมล่างขวาเพื่อปรับขนาด หรือกรอกตัวเลขด้านล่างให้แม่นยำ

💬 คลังคำคมและข้อความกิจกรรม

ข้อความทั้งหมดถูกจัดเก็บเป็น Data ใน QuoteStore ไม่มีการ Hard-code ในระบบ

✏️ เพิ่ม/แก้ไขข้อความ

🛡️ จัดการเนื้อหาและภาพกิจกรรม (Moderation)

ผู้ดูแลระบบสามารถซ่อน ลบ หรือตรวจสอบรายงาน

ไม่มีภาพกิจกรรมในระบบขณะนี้

☁️ การเชื่อมต่อ Google Drive Storage

⚪ ยังไม่ได้เชื่อมต่อ

ระบบใช้ Google Apps Script Web App เป็นสะพานเชื่อมไปยัง Google Drive โดยตรง ทำให้จัดเก็บภาพและซิงก์ข้อมูลได้อย่างปลอดภัย ไม่ต้องใช้เซิร์ฟเวอร์

🚀 วิธีสร้างและ Deploy Google Apps Script (3 นาที):

1
ไปที่ script.google.com แล้วกดปุ่ม "โครงการใหม่" (New project)
2
กดปุ่ม "📋 คัดลอกโค้ด Google Apps Script" ด้านบน แล้วนำไปวางแทนที่เนื้อหาในไฟล์ Code.gs ทั้งหมด จากนั้นกดบันทึก 💾
3
กดปุ่มสีน้ำเงิน "ทำให้ใช้งานได้" (Deploy) มุมบนขวา → เลือก "การทำให้ใช้งานได้รายการใหม่" (New deployment)
4
เลือกประเภท "เว็บแอป" (Web app) | ดำเนินการในฐานะ: ฉัน (Me) | ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone) → กด "ทำให้ใช้งานได้"
5
คัดลอก URL เว็บแอป ที่ได้มาวางในช่องด้านบน แล้วกด "💾 บันทึกการตั้งค่า" ได้ทันที!

📁 โครงสร้างโฟลเดอร์อัตโนมัติบน Google Drive:

Photo Frame Studio/
├── Photo_Log           (Google Sheet บันทึกวันเวลา ชื่อภาพ และลิงก์ไฟล์)
├── Frames/             (ไฟล์ PNG กรอบรูปภาพ)
├── Original Photos/    (ภาพต้นฉบับของผู้ร่วมกิจกรรม)
├── Finished Images/    (ภาพประกอบกรอบที่บันทึกแล้ว)
└── Activity Images/    (ภาพที่ส่งเข้าร่วมกิจกรรมบน Wall)

📦 สำรองข้อมูลและกู้คืน (Backup & Restore)

จัดการข้อมูลทั้งหมดของระบบ (กรอบภาพ คำคม ประวัติกิจกรรม และการตั้งค่า) ดาวน์โหลดเป็นไฟล์ JSON หรือกู้คืนข้ามอุปกรณ์ได้ทันที

📥 ส่งออกข้อมูล (Export Backup)

ดาวน์โหลดข้อมูลระบบทั้งหมดเป็นไฟล์ JSON เพื่อสำรองเก็บไว้ในคอมพิวเตอร์ของคุณ

📤 นำเข้าข้อมูล (Import Restore)

เลือกไฟล์ Backup (.json) เพื่อกู้คืนข้อมูลกรอบภาพและคำคมทั้งหมด

⚠️ รีเซ็ตระบบ (Reset to Defaults)

ล้างแคชในเครื่องและโหลดข้อมูลเริ่มต้นทั้งหมด (5 กรอบรูปมาตรฐาน, 7 หมวดคำคม)

🌐

อัปเดตข้อมูลขึ้นระบบส่วนกลางให้ทุกคนเห็น (Method B — GitHub Master Sync)

เมื่อ Admin แก้ไข/เพิ่มกรอบรูปหรือคำคมในหน้านี้แล้วต้องการให้ผู้ใช้ทุกคนทั่วโลกเห็นตรงกันแบบถาวร ให้กดดาวน์โหลดไฟล์ด้านล่าง แล้วนำไปวางทับในโฟลเดอร์ config/ แล้ว Push ขึ้น GitHub ได้ทันที!
